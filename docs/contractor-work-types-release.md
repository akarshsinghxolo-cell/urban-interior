# Contractor work types release

Production release note for the audited contractor pricing separation shipped on 2026-08-25.

- Work subcategories support editable Budget, Standard, Premium, Luxury, or custom work types with independent execution unit, material rate, labour rate, total rate, and notes.
- Contractor capabilities and canonical rates use labour-only work-type pricing.
- Contractors no longer select or price scoped material articles.
- Vendor article, variant, brand, availability, and lead-time workflows remain independent of contractor work types.
- Scoped material article names are editable in Master Setup.
